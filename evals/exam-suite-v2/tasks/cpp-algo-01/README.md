# Свободный слот мастерской (C++)

Контракт — файл `solution.h` (лежит рядом, менять нельзя). Напиши `solution.cpp` с реализацией (включи "solution.h").

Семантика: `busy` — полуоткрытые интервалы (пересечения и любой порядок допустимы); вернуть самый ранний [t, t+duration], целиком свободный внутри [day_start, day_end); если нет — nullopt.
