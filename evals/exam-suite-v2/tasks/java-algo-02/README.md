# Поток маяка (Java)

Класс `Task` со статическим методом:

`public static String decodeBeacon(String stream)`

Формат: "<count><symbol>[!]..." + "#N": каждая '!' = +1 повтор предыдущего символа; контрольная сумма — сумма итоговых количеств (число + bang-повторы) mod 97 должна равняться N. Нет '#N' или не сошлась — IllegalArgumentException. Вернуть развёрнутую строку.
