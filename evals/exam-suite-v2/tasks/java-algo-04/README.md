# Минимальное окно наблюдений (Java)

Класс Task: `public static int[] minWindow(java.util.List<String> events, java.util.List<String> required)`

Кратчайшее [i, j) (вернуть {i, j}), покрывающее каждый тег required хотя бы раз; при равной длине - меньший i; нет покрытия - null; пустой required - {0,0}.
