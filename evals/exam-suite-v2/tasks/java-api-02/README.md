# Номера сети "Гранит-фон" (Java)

Класс Task: `public static java.util.List<String> validNumbers(java.util.List<String> numbers)`

Формат: 'G' + 2..6 цифр + '-' + 1..4 цифр; 'G' строго верхний; вторая группа не начинается с '0'. Вернуть только валидные в исходном порядке. Регистр букв, кроме 'G', не допускается вовсе (только цифры и дефис в указанных местах).
