# Свободный слот мастерской (JS)

Мастерская "Ковалка": рабочий день с dayStart до dayEnd (минуты от полуночи), busy — массив [s, e] полуоткрытых интервалов (могут пересекаться, любой порядок).

Экспортируй `firstFreeSlot(busy, duration, dayStart, dayEnd)`: самый ранний [start, start+duration], целиком свободный внутри дня; `null`, если нет. Слоты нулевой длины не считаются занятостью. duration <= 0 — бросить Error.
