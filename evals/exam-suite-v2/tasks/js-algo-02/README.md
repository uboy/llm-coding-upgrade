# Поток маяка (JS)

Строка фрагментов `<count><symbol>`, после символа могут быть `!` (каждая = +1 повтор предыдущего символа). В конце `#N` — контрольная сумма: сумма итоговых количеств (число + bang-повторы) по модулю 97 должна равняться N.

Экспортируй `decode(stream)`: развёрнутая строка; нет `#` или сумма не сошлаcь — Error.
