# Минимальное окно наблюдений (JS)

events — массив тегов-строк, required — массив обязательных уникальных тегов. Экспортируй `minWindow(events, required)`: кратчайший полуоткрытый диапазон индексов [i, j), покрывающий каждый тег required хотя бы раз; при равной длине — меньший i; нет покрытия — null. Пустой required — [0, 0].
