# Query-строки API "Плёс"

Экспортируй пару функций:
- `parseQuery(qs: string) -> object`: строка без ведущего `?`. Ключи без `[]` — строка; `k[]=v1&k[]=v2` — массив; `k[v]=x` — объект (один уровень); повторённый простой ключ — ПОСЛЕДНЕЕ значение побеждает (не массив). `+` — пробел, %-декодинг обязателен (decodeURIComponent, при ошибке декодинга — Error).
- `stringify(obj) -> string`: обратная операция, ключи в порядке вставки; пустой объект — ""; массивы через `[]`; вложенный объект через `[k]`; null/undefined значения — ключ без `=`.

parse(stringify(x)) должен восстанавливать x для объектов указанной формы.
