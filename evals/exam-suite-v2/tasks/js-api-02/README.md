# Табличный формат "Талка"

CSV-подобный формат: первая строка — заголовок; разделитель — запятая ИЛИ точка с запятой (детект по первой строке: чего больше, то и разделитель всего файла); поля могут быть в двойных кавычках, внутри кавычек `""` — литеральная кавычка; перевод строки внутри кавычек — часть поля.

Экспортируй `parseTalka(text) -> array of objects` (ключи — заголовки). Пустые строки пропускаются. Число строк данных — любое. Все значения — строки (без типизации).
