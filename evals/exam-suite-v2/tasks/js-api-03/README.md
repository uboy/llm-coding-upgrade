# Расписание кассы "Кассандра"

Мини-DSL расписания: `"<days>@<hh:mm>-<hh:mm>"`, дней: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`; диапазон дней через дефис (`mon-fri`), несколько групп через запятую.

Экспортируй `expandSchedule(expr: string) -> string[]`: плоский отсортированный список слотов `"DAY HH:mm-HH:mm"` (день полными именами, как в списке выше; сортировка по порядку дней недели с понедельника, затем по времени начала). Ошибки: неизвестный день, минута > 59, час > 23, конец раньше/равен началу, мусор — Error.

Пример: expandSchedule("mon-fri@09:00-10:00,sat@11:30-12:00") -> 6 слотов, понедельник 09:00 первым.
