# Мини-JSON "Послабее"

Парсер ПОДМНОЖЕСТВА JSON с послаблениями: одинарные и двойные кавычки строк; однострочные комментарии `//` и блочные `/* */`; висячая запятая в массивах/объектах; неключевые слова null/true/false как есть.

Экспортируй `looseParse(text)`: значение (объект/массив/строка/число/bool/null). Ошибки (Error): незакрытая строка/скобка/комментарий, два значения подряд. Строки: распознаются escape `\'`, `\"`, `\\`, `\n`; прочий escape-символ после обратного слэша вставляется как есть (сам слэш теряется). Внутри кавычек допустимы литеральные переводы строк (многострочные строки).
