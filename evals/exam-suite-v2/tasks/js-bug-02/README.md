# Баг: батч-загрузка "Караван"

solution.mjs: `loadAll(fetchers)` — принимает массив функций, возвращающих Promise<string>, должен вернуть Promise массива результатов В ПОРЯДКЕ fetchers, устойчиво к отказам: если промис упал, в результате на его месте null (остальные грузятся).

Багов два: (1) при reject вся функция падает целиком; (2) при использовании Promise.all с map+async порядок может нарушаться из-за преждевременного выхода — проверь тест "mixed delays": результаты обязаны соответствовать порядку входа, а не времени ответа. Исправь, сохранив сигнатуру.
