# Баг: метки месяцев "Лунник"

solution.mjs: `monthName(isoDate)` — из строки "YYYY-MM-DD" возвращает имя месяца по-русски в именительном падеже. Тесты падают на дате "2024-03-09" (и любой день <= 12): классическая ловушка new Date("YYYY-MM-DD") даёт UTC-полночь, а локальная зона смещает день/месяц.

Исправь БЕЗ Date-парсинга строки: разбирай компоненты строки вручную. Имена: январь..декабрь. Неверный формат (не YYYY-MM-DD, месяц 00/13, день 00/32) — Error.
