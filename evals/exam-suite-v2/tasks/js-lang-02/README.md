# Асинхронный итератор по страницам "Лента"

Экспортируй `paginate(fetchPage)`:
- fetchPage(cursor) — асинхронная функция, возвращает { items: [], nextCursor: string | null }.
- Возвращаемый объект асинхронно-итерабелен (Symbol.asyncIterator): for-await отдаёт элементы по одному, дочитывая страницы лениво (новую страницу запрашивает только когда кончились элементы текущей).
- Пустые страницы допустимы: итерация продолжается, пока nextCursor !== null.
- Ручной контракт тоже: методы next() согласно протоколу {value, done}.

Использовать Symbol.asyncIterator обязательно.
