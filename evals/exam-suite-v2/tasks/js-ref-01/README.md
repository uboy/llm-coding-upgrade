# Рефактор: пирамида колбэков "Зиккурат"

solution.mjs: `loadProfile(userId, api, done)` — callback-style: грузит профиль, потом настройки, потом аватар; собирает {profile, settings, avatar} (avatar опционален: ошибка его загрузки не фейлит всё, просто avatar: null). Работает, но это вложенные колбэки.

Отрефактори на async/await (внутренние хелперы-обёртки промисов допустимы), сохранив контракт: done(err, result); ошибки профиля/настроек → err; аватарная ошибка → avatar null. Экспорт только loadProfile.
