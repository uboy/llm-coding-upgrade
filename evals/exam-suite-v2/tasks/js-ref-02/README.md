# Рефактор: калькулятор тарифа "Гиря"

solution.mjs: `calc(plan, minutes)` — план "light"/"standard"/"premium": включённые минуты + цена сверх. Лесенка switch. Отрефактори на таблицу планов (данные вместо ветвлений), экспортируй также константу PLANS. Поведение по тестам; неизвестный план — Error.

Тарифы: light: 30 мин вкл, 1.5/мин дальше; standard: 100 вкл, 1.0; premium: 300 вкл, 0.8. Сумма округляется до копеек (х2, Math.round, /2).
