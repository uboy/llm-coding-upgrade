# Светофор "Мираж"

Класс `TrafficLight extends` вашего мини-эмиттера или встроенного EventEmitter — на твой выбор, НО публичный контракт такой:

- `new TrafficLight()` — старт: red, фаза 0.
- `tick()` — следующая фаза цикла red -> red-yellow -> green -> yellow -> red...
- `state` — геттер, текущая фаза.
- событие `"change"` эмиттится при каждом tick с аргументом новой фазы.
- `onRed(cb)` — одноразовая подписка: cb вызывается, когда фаза станет red (после текущего момента), подписка снимается после срабатывания.

Фазы: "red", "red-yellow", "green", "yellow".
