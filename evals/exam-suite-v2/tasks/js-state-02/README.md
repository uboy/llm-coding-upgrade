# Debounce с ручными часами "Тиктак"

Экспортируй `createDebounce(fn, waitMs, clock)`:
- `clock` — объект с методами `now()` (мс) и, главное, вы сами вызываете его `advance(ms)` в тестах: сделай часы сами, если не переданы — используй performance.now(). Сигнатура: `createDebounce(fn, waitMs, clock = null)`.
- Возвращаемый объект: `{ call(...args), flush(), cancel() }`.
- `call` — откладывает запуск: fn выполнится с аргументами ПОСЛЕДНЕГО call, когда с момента последнего call пройдёт waitMs (по часам clock).
- `flush()` — выполнить немедленно с последними аргументами, если был отложенный вызов (и сбросить таймер).
- `cancel()` — забыть отложенный вызов (fn не выполняется).
- Время проверяется методом `clock.now()`; таймеры/son performance — нельзя (тесты ручные). Проверку «пора ли» делай лениво: в call/flush и в отдельном методе `tick()`, который тест вызывает после advance.

Контракт для тестов: `{ call, flush, cancel, tick }`; `tick()` до/executed запускает fn, если waitMs истёк.
