# Debounce с ручными часами "Тиктак"

Экспортируй ДВЕ функции:

1. `createManualClock()` — ручные часы: `{ now(): number, advance(ms) }` (старт с 0).
2. `createDebounce(fn, waitMs, clock = null)` — debounce поверх переданных часов
   (без clock — performance.now, в тестах всегда передаётся). Возвращает `{ call(...args), flush(), cancel(), tick() }`:
   - `call` откладывает запуск: fn выполнится с аргументами ПОСЛЕДНЕГО call, когда с момента него пройдёт waitMs;
   - готовность проверяется лениво в `tick()` (тест вызывает tick после advance; без истечения waitMs fn не вызывается);
   - `flush()` — выполнить немедленно с последними аргументами, если был отложенный вызов;
   - `cancel()` — забыть отложенный вызов (fn не выполняется).
Никаких таймеров (setTimeout/setInterval) — только часы clock.
