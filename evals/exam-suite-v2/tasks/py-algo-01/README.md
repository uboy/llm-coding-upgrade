# Свободный слот мастерской

Мастерская "Ковалка" работает с `day_start` до `day_end` (минуты от полуночи).
Вам дан список занятых слотов `busy = [(s1, e1), ...]` (полуоткрытые интервалы, могут пересекаться и идти в любом порядке).

Реализуй `first_free_slot(busy, duration, day_start, day_end) -> tuple[int, int] | None`:
возвращает **самый ранний** интервал `(start, start + duration)`, который целиком свободен и лежит внутри рабочего дня, или `None`, если такого нет.

- Слоты нулевой длины занятостью не считаются.
- `duration <= 0` — `ValueError`.
- Ответ должен начинаться не раньше `day_start` и заканчиваться не позже `day_end`.
