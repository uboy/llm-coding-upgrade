# Поток маяка

Датчик-маяк шлёт строку из фрагментов вида `<count><symbol>`, например `"3a2b10c"`.
После символа может стоять флаг `!`: он означает "повторить предыдущий символ ещё раз" (например `"3a!"` = 4 `a`).

Реализуй `decode(stream: str) -> str`:
1. Разбор слева направо: число (может быть многозначным), затем символ, затем необязательные `!`.
2. Контрольная сумма: сумма всех итоговых количеств символов (число плюс `!`-повторы) по модулю 97 должна равняться числу после `#` в конце строки (`"...#42"`). Если фрагмента `#` нет или сумма не сошлась — `ValueError`.
3. Вернуть развёрнутую строку.

Пример: `decode("3a2b#5")` -> `"aaabb"` (3+2=5).
