# Порядок блюд шефа

Шеф-повар составляет порядок приготовления блюд. Дано `deps = {"борщ": ["бульон", "свёкла"], ...}`: ключ — блюдо, список — что должно быть готово ДО него.

Реализуй `cooking_order(deps: dict) -> list`:
1. Вернуть список всех блюд (включая ингредиенты-вершины без зависимостей) в порядке приготовления.
2. Порядок — лексикографически минимальный из корректных (сравнение строк, регистр не важен: сравнивай в lower).
3. Цикл — `ValueError`.

Пример: `{"суп": ["вода"], "вода": []}` -> `["вода", "суп"]`.
