# Минимальное окно наблюдений

Телеметрия — список строк-тегов `events`. Дан обязательный набор `required` (все элементы различны).

Реализуй `min_window(events, required) -> tuple[int, int] | None`:
самый короткий по длине полуоткрытый диапазон индексов `[i, j)`, внутри которого встречается каждый тег из `required` хотя бы раз. При равной длине — с меньшим `i`. Если покрытия нет — `None`.

- Пустой `required` — `(0, 0)`.
- Теги вне `required` игнорируются.
