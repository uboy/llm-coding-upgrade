# Номера сети "Гранит-фон"

Формат внутреннего номера: `G` затем 2-6 цифр, затем дефис и 1-4 цифры (пример: `G123-45`).
Реализуй `validate(numbers: list[str]) -> dict`:
- `"valid"`: список валидных номеров как есть;
- `"normalized"`: словарь валидный номер -> нормализованный вид (дефис убрать, префикс `G` заменить на `g`: `G123-45` -> `g12345`);
- `"errors"`: словарь неверный номер -> код ошибки.
Коды: `"format"` (не совпал с шаблоном), `"group"` (вторая группа цифр начинается с 0).
Регистр буквы `G` строго верхний.
