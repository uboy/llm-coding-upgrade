# Гроссбух "Счёт-Копейка"

Суммы хранятся ЦЕЛОЧИСленно в копейках (никаких float!). Записи — строки:
`"<dd.mm.yyyy>|<account>|<D|C>|<amount>"`, amount — целые копейки без знака.

Реализуй `balance(entries: list[str]) -> dict`:
1. Парсинг: неверная дата (несуществующий день/месяц), неизвестный тип операции, нецелое/отрицательное количество, неверное число полей — пропускать запись и включать её в `"skipped"`.
2. По каждому счёту: дебет `D` уменьшает, кредит `C` увеличивает итог.
3. Вернуть `{"balances": {account: итог_в_копейках}, "skipped": [записи как есть]}`.

Года високосность учитывать (29.02 високосного года валидно, невисокосного — нет).
