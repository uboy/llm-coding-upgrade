# Шаблонизатор "Клич"

Шаблон содержит плейсхолдеры `{{name}}` и `{{name|фильтр}}`. Доступные фильтры:
- `up` — верхний регистр;
- `low` — нижний регистр;
- `trunc:N` — обрезать до N символов (N >= 0);
- `default:TEXT` — подставить TEXT, если ключа нет в контексте (иначе TEXT игнорируется).

Реализуй `render(template: str, ctx: dict) -> str`:
1. `{{name}}` без фильтров: нет ключа — `ValueError`.
2. Фильтры можно комбинировать через `|` слева направо: `{{title|trunc:3|up}}`.
3. `default` имеет смысл только первым фильтром в цепочке; если он не первый — `ValueError`.
4. Неизвестный фильтр — `ValueError`. Всё вне `{{...}}` — как есть.
5. Пробелы вокруг имени и фильтров игнорируются: `{{ name | up }}`.
