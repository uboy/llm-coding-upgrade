# KVLite: парсер конфигурационного формата

Реализуй модуль `kvlite.py` с единственной функцией `parse(text: str) -> dict`.

KVLite — компактный формат ключ-значение. Правила:

1. **Строки**: парсер работает построчно.
2. **Комментарии**: строка, начинающаяся с `#` (после пробелов), игнорируется.
3. **Пустые строки** (только пробелы) игнорируются.
4. **Секции**: строка `[name]` открывает секцию. Все последующие ключи попадают
   во вложенный словарь с этим именем. Секцию нельзя объявлять дважды —
   это ошибка. Секции создают ровно один уровень вложенности.
5. **Пары**: строка вида `key = value`. Пробелы вокруг ключа и значения
   обрезаются. Пустое значение после `=` — ошибка.
6. **Значения**:
   - строка в двойных кавычках: `"..."` с escape-последовательностями
     `\n` (перевод строки), `\t` (таб), `\\` (обратный слэш), `\"` (кавычка);
     неизвестный escape — ошибка;
   - целое: `-?\\d+`;
   - дробное: `-?\\d+\\.\\d+`;
   - булево: `true`/`false`/`on`/`off` без учёта регистра;
   - массив: `[v1, v2, ...]` — элементы через запятую, каждый элемент —
     любое скалярное значение из правил выше (включая кавычки), пробелы
     вокруг элементов обрезаются, пустой массив `[]` допустим;
   - всё остальное — «голая» строка до конца строки (обрезана).
7. **Дубликаты ключей**: значение последнего вхождения побеждает.
8. **Порядок**: обычный dict, порядок вставки не проверяется.
9. **Ошибки**: любая нераспознанная строка, неизвестный escape, повторная
   секция или пустое значение — `ValueError` с сообщением, содержащим
   номер строки (1-based).

До первой секции ключи кладутся в корень результата.

## Пример

```ini
# комментарий
app_name = "reporter"
verbose = on

[server]
host = 127.0.0.1
ports = [8080, 8443]
```

даёт

```python
{
    "app_name": "reporter",
    "verbose": True,
    "server": {"host": "127.0.0.1", "ports": [8080, 8443]},
}
```
