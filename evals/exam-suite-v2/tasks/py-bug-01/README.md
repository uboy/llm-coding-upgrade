# Баг: кольцевой буфер "Обруч"

Файл `solution.py` реализует кольцевой буфер фиксированной ёмкости (`RingBuffer(n)`):
`push(x)` добавывает, при переполнении перезаписывает самый старый элемент; `snapshot()` возвращает элементы от самого старого к новому; `last()` — последний добавленный.

Тесты падают. Найди и исправь баг (их может быть больше одного: проверь перенос индекса при переходе через границу и учёт неполного заполнения). Сигнатуры не менять. `last()` на пустом буфере — IndexError. `snapshot()` пустого — [].
