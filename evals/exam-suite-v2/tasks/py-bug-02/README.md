# Баг: flatten вложенных списков "Слоёный"

`flatten(items)` должна разворачивать произвольно вложенные списки/кортежи в плоский список. В текущей реализации есть два бага:
1) на вложенных структурах с повторяющимися ссылками (один и тот же подсписок внутри себя — напрямую или транзитивно) рекурсия не завершается;
2) строки разворачиваются посимвольно, хотя строка — атомарный элемент.

Исправь. Строки (любые) — листья. Списки и кортежи — контейнеры.
