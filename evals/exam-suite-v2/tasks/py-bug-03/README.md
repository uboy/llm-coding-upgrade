# Баг: округление тарифа "Полушка"

`apply_rate(amount_kopecks: int, permille: int) -> int` считает amount * permille / 1000 (промилле) с банковским округлением до целых копеек (half-to-even: 0.5 округляется к чётному).

Текущая реализация использует float и round() и выдаёт неверные результаты на больших суммах (потеря точности double) и на "граничных" половинах в меньшую сторону. Реализуй ЦЕЛОЧИСЛЕННО (без float), с корректным half-to-even.

Примеры: 5 * 500 = 2.5 -> 2; 15 * 100 = 1.5 -> 2; 123456789012 * 15 (18.5...) по правилу half-even.
