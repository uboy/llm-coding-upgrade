# Транзакционный блок "Реквизит"

Реализуй контекстный менеджер (класс с __enter__/__exit__, не contextlib) `transaction(steps)`:
- steps — список кортежей (do, undo); do/undo — функции без аргументов, undo может быть None.
- __enter__ выполняет все do по порядку.
- Если do бросил: выполнить undo УЖЕ выполненных шагов в обратном порядке, прокинуть исходное исключение дальше (не оборачивать). Шаг с упавшим do в undo не участвует.
- Если во время отката undo сам упал: продолжить остальные откаты; после — прокинуть исходное исключение, дополнив его атрибутом rollback_errors (список ошибок отката).
