# Дескриптор "Прецедент"

Реализуй дескриптор `Cached(dependency)`:
- вешается на атрибут класса (например `total = Cached("load")`), имя метода-источника задаётся конструктором;
- первое чтение `obj.total` вызывает `obj.load()` и кэширует результат в `obj.__dict__["_cached_total"]`; повторные чтения берут кэш, метод больше не вызывается;
- запись `obj.total = X` — `AttributeError` (read-only, всегда);
- инвалидация: метод дескриптора на атрибуте класса — `Box.total.invalidate(obj)` — удаляет кэш (ключ `_cached_<имя>`), следующее чтение пересчитывает;
- кэш у каждого экземпляра свой;
- используй `__set_name__` для получения имени атрибута.
