# Дескриптор "Прецедент"

Реализуй дескриптор Cached(dependency): атрибут класса; первое чтение obj.attr вызывает self.<dependency>() (метод) и кэширует результат в obj.__dict__ (дальше работает обычный атрибут, метод не вызывается).

- Cached.invalidate(obj, name) — статический: удалить кэш obj.__dict__.pop(name, None), следующее чтение пересчитывает.
- Запись obj.attr = X — AttributeError (read-only).
- __set_name__ используй для получения имени атрибута.

Кэш хранится в obj.__dict__ под ключом `_cached_<имя-атрибута>`. Инвалидация: дескриптор предоставляет метод `invalidate(obj)` (на атрибуте класса: `Box.total.invalidate(box)`).
