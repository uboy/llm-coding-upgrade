# Рефактор: валидатор формы "Анкета-3"

Файл `solution.py` содержит работающую, но монолитную функцию `validate_form(data) -> list[str]` (список кодов ошибок, пустой = ок). Поведение описано тестами.

Отрефактори в композицию маленьких валидаторов (по одному правилу), сохранив ПУБЛИЧНЫЙ API: `validate_form(data) -> list[str]`, тот же список кодов в том же порядке. Условия: каждая проверка — отдельная функция; никакой проверки-«босса» длиннее 5 строк; дубликация текста ошибок устранена через константы.
