# Лифт "Стрела"

Класс `Elevator(floors: int, capacity: int)`; этажи пронумерованы 1..floors, старт на 1, двери закрыты.

Методы:
- `call(floor)` — цель; дверь должна быть закрыта (`close_door()` перед движением, если открыта — ошибка состояния `RuntimeError`).
- `step()` — переместиться на 1 этаж в сторону ближайшей по направлению цели; по прибытии на цель — остановиться и ОТКРЫТЬ двери (цоль снимается).
- `board(n)` — войти n пассажиров (двери открыты, иначе `RuntimeError`); перегруз (n + текущие > capacity) — `ValueError`, состав не меняется.
- `close_door()` / `open_door()` — состояние дверей; ехать с открытыми дверями нельзя.

Свойства: `current` (этаж), `doors_open` (bool), `passengers` (int).
Цели хранятся множеством; движение к ближайшей цели (при равенстве — вниз).
