# Кэш с зависимостями "Матрёшка"

Класс `DepCache`:
- `put(key, value, deps: list = [])` — записать; `deps` — ключи, от которых зависит значение. Зависимость на несуществующий ещё ключ допустима.
- `get(key)` — значение или KeyError.
- `invalidate(prefix: str)` — удалить все ключи, начинающиеся с prefix, И все ключи, которые (транзитивно, через deps) зависели от удалённых.
- `keys()` — отсортированный список живых ключей.
- invalidated-ключ, у которого раньше были deps на удалённые, при повторном `put` живёт снова.

Циклы в deps при invalidate не должны вешать алгоритм.
