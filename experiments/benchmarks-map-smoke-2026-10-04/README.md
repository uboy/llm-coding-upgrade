# Smoke-прогон полного цикла бенчмаркинга на сервере (2026-10-04)

Проверка работоспособности всей цепочки из docs/task-benchmarks-map.md на
v100-host одним заходом. Заказ владельца: «запустим проверку, как работает
бенчмаркинг полностью на сервере».

## Выводы

1. **Репродьюсibility:** probes base = 1/6 отказов и 83.7 ток/с против утреннего
   1/6 и 83.2 - шум в пределах ~0.6%, методика стабильна.
2. **Дискриминация экзамена:** базовая gemma4-26B не решает код (0/2) и
   половину знаний (1/2) - сьют различает модели, как и задуман (smoke
   hy3-free 3/6 для сравнения).
3. Полный цикл «обновил данные → поднял модель → прогнал бенчмарк → получил
   results.json» работает на сервере без ручных костылей; повторяется
   тремя командами (скрипт с asrock; docker run; probe + runner).

## Артефакты

- `results.json` - раннер экзамена (метаданные прогона 20261004T201619).
- `probes.json` - сырые ответы probe-батареи.
- TSV/linkcheck от этого дня - в `benchmarks-map/` (прогон с asrock).

Состояние хоста после прогона: eval-контейнер удалён, GPU2 возвращён
(v52-2 7.9 ГБ, как до старта).
